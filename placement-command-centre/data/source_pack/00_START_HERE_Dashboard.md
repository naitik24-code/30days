# 30-Day Placement Command Centre

> Goal: rebuild fundamentals, practise aptitude and coding daily, ship evidence from SteelLens / OptiVest AI / QuantOpt, apply off-campus, and improve communication. Sustainable consistency beats sacrificing sleep.

## Daily non-negotiables
- [ ] Aptitude: 10–25 questions; record accuracy and mistakes
- [ ] Coding / DSA: learn one concept and solve independently
- [ ] SQL or Core CS: short daily recall session
- [ ] Project: ship one small, verifiable improvement
- [ ] Apply to 3–5 relevant roles and log every application
- [ ] Send 5 thoughtful LinkedIn connection requests (quality over spam)
- [ ] Speaking: record or practise for 10–20 minutes
- [ ] Instagram: capture a learning note, draft, or useful post
- [ ] Revision: recall yesterday's concepts without notes
- [ ] Protect sleep and record energy honestly

## Main databases to import
Import each CSV below separately using Notion's **Settings → Import → CSV** or the workspace Import menu. Then use `/linked view of database` to place the databases on this page.

1. **30-Day Roadmap** — day-by-day assignments across aptitude, technical, projects, speaking, job search, Instagram, and review.
2. **Master Question Tracker** — 126 coding / technical exercises; use Status and Confidence to decide what to revisit.
3. **Project Upgrade Board** — tasks for SteelLens, OptiVest AI, and QuantOpt. Do not include the separate Competency-Based AI Hiring Engine project.
4. **Job Application Tracker** — one row per role; add company, role, job URL, resume version, status, follow-up date, and outcome.
5. **Daily Scorecard** — log effort and evidence daily; do not judge progress by hours alone.
6. **Spaced Revision Tracker** — schedule same-day, next-day, Day 3, Day 7, and Day 14 recall.
7. **Interview Question Bank** — practise aloud and rate confidence.
8. **Basics Learning Path** — work through fundamentals in order.
9. **Daily Operating System** — reference timetable that fits college from 9:30 AM to 4:30 PM.
10. **Weekly Review** — choose three priorities for the next week.
11. **Day 1 Starter** — baseline and setup checklist.
12. **Original Tracker Backup** — preserve the original tracker for reference.

## Import instructions
1. Download and unzip `Notion_30_Day_Placement_Command_Centre_Import_Kit.zip`.
2. In Notion, create a page called **30-Day Placement Command Centre**.
3. Import this Markdown file as a page (or copy/paste its content into a Notion page).
4. Import each CSV one at a time. Each becomes its own database.
5. For each database, set the property types (Status → Status/Select, dates → Date, confidence → Number, check fields → Checkbox where appropriate).
6. Return to the home page and add linked views of the databases using `/linked view of database`.
